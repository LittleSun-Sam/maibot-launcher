## 八、已知事项（非违规，但需知悉）

1. **端口默认值曾有错误，已修正；协议端改为 SnowLuma 后端口再次整体更新** ——
   早期版本协议端用的是**注入式**的那种，其端口曾被写成 `6199`
   （实际上那是 **AstrBot** 的反向 WS 端口，那个协议端自身并不监听它）。
   后来一度核实为 `3001` / `6099`。

   **现在协议端只剩 SnowLuma，启动器的端口常量已随之改为**
   （出处见 `src/main/constants.js` 的注释）：

   | 用途 | 端口 | 出处 |
   |---|---|---|
   | MaiBot 主服务 | `8080` | MaiBot `src/config/startup_bindings.py` |
   | MaiBot WebUI | `8001` | MaiBot `src/config/startup_bindings.py` |
   | SnowLuma WebUI | `5099` | SnowLuma 启动日志与 `config/runtime.json` 的 `webuiPort` |
   | SnowLuma OneBot 正向 WebSocket | `7988` | SnowLuma 适配器要去连的端口 |

   `service.snowlumaPorts`（与 `service.ports` 分开命名空间）分别承载
   SnowLuma 的 WebUI 与 OneBot 端口；总览页的「检查」会**真的去连**这两个端口，
   判断 SnowLuma 是否真的可以接受适配器的连接。

   ⚠️ **需复核的一点**：`7988` 与 `5099` 的性质与旧协议端不同 ——
   实测 SnowLuma 启动后只监听 WebUI 的 `5099`，它生成的 `config/runtime.json`
   里**没有 OneBot 段**，OneBot 正向 WS 服务器需要用户在 SnowLuma 自己的 WebUI 里
   新建，端口也由用户在那一步决定。因此这两个值应当理解为
   **"启动器的默认值与自检目标值"**，而不是"可以从配置里读到的上游默认值"。

   > 顺带修正一处历史结论：早期版本还记录过 `ports.webui = 8090`，
   > 那是早期前端硬编码的空想值（`8090` 实为 MaiBot API Server 端口），
   > 已在 `settings.js` 的一次性迁移里改为 `8001`。

2. **项目目录名为 `maibot-tauri`，实际是 Electron** —— 历史遗留命名，
   已在 `constants.js` 与 `README.md` 中注明。

3. **MaiBot 官方发行包自带游戏素材** —— 经查，MaiBot 1.2.3 的发行目录中
   包含游戏相关美术资源（非本项目分发，由 MaiBot 团队提供）。
   **与本项目无关**，本项目不包含这些文件。

4. **RizUI 仓库未附带许可证文件** —— 默认"保留所有权利"。
   本项目与它**无任何代码关联**（未作为依赖、未复制源码、命名零重叠），
   故不涉及该仓库的许可问题。
